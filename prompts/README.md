# 可复用提示词

本目录用于保存经过验证的任务提示词。提示词按工作阶段组织，而不是按某个模型品牌组织。

推荐后续文件：

- `01_reconnaissance.md`：项目和题目侦察。
- `02_problem_formulation.md`：问题重述、假设、符号和候选模型。
- `03_data_audit.md`：数据字典、质量检查和泄漏审计。
- `04_modeling.md`：baseline、复杂模型、优化和敏感性分析。
- `05_validation.md`：实验设计、指标和复现检查。
- `06_paper_review.md`：论文证据链、格式和交叉审阅。

模板正文见 `research/prompt-playbook.md`。每次实际使用后，应记录输入文件、模型版本、输出文件和人工修改点。
