# 优秀论文本地参考库

本目录是上一次资料收集过程中已下载到工作区的本地论文样本，当前包含 2023、2024、2025 三届研究生数学建模竞赛优秀论文，共 103 个 PDF，约 0.75 GiB。

## 目录结构

- `2023年研究生数学建模竞赛优秀论文选/`：按 A--F 题前缀归档。
- `2024年研究生数学建模竞赛优秀论文选/`：按 A--F 子目录归档。
- `2025年研究生数学建模竞赛优秀论文选/`：按 A--F 题优秀论文子目录归档，文件名包含题名。

## 使用方式

1. 先阅读 `research/source-catalog.md` 和 `research/problem-trends.md`，确定论文与当前小问的相关性。
2. 一次只选少量同题论文，建立 `research/notes/` 阅读卡片；不要让 Codex 无差别扫描全部 PDF。
3. 阅读时区分原文明确内容、根据代码推断的内容和本项目新增内容，记录页码或章节。
4. 论文中的结果只用于学习建模结构、验证设计和写作表达，不能直接作为本队实验结果或结论。

## 来源与版权

这些 PDF 是公开资料的本地缓存，文件名和目录结构保留了下载时的题目分类；具体原始发布地址、授权状态和文件哈希需要在正式引用前逐份核验。版权归原作者、竞赛主办方或原发布平台所有，仅作个人学习和竞赛准备使用，不应对外再分发。

## 版本控制

论文 PDF 体积较大且版权边界不适合提交 Git。项目 `.gitignore` 默认忽略本目录中的 PDF，但保留本 `README.md`，因此本地资料不会被误提交。
