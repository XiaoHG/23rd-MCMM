# 版本分析

## 版本定位与边界

v2 是 E 题的“题目侦察、方案设计与数据审计设计”版本。其目标不是直接训练一个复杂模型或生成论文结论，而是将问题 1--3 串成可执行、可验证、可解释的技术路线，并规定数据读取、baseline、实验比较和结果交付的边界。v1 已完成 E 题工作副本初始化；v2 应在此基础上明确后续实现应产出的数据字典、实验配置、模型接口和验证证据。

本次版本要求提出可参考历年优秀论文的思路，但当前版本记录未列出任何已核验的论文、页码或实验设置。因此，往届论文只能在后续资料检索、原文核对和阅读卡片完成后作为方法启发使用，不能在本版本中将任何往届方法、获奖信息或实验数字表述为已证实事实。以下方案均为候选实施路线，最终模型选择必须以题给数据上的验证集结果、鲁棒性与可解释性证据决定。

## 题目重述与总体解题框架

E 题包含三条递进链路：问题 1 从 100 条原始视频得到可追溯的文本、音频和视觉特征及时序对齐；问题 2 在局部连续时段模态缺失下联合预测情感极性和连续情感强度；问题 3 在三模态完整的专项样本上输出预测结果、主要参考模态和可回溯至原始素材的关键证据。三问不能割裂处理：问题 1 的样本 ID、时间轴、有效长度和特征规范决定问题 3 是否可以将解释映射回原始片段；问题 2 的缺失机制和鲁棒融合决定其泛化边界。

建议采用四层框架：

1. **数据治理层**：建立文件清单、样本 ID 映射、标签字典、特征形状、有效长度、缺失掩码和原始视频时间轴映射；原始文件只读，所有派生数据和日志可追溯。
2. **表示与对齐层**：对问题 1 的视频、音频、文本使用统一时间锚点或明确的非对齐双流时间轴；输出时必须记录填充、截断和每个序列位置对应的原始时间区间。
3. **预测与鲁棒层**：先以 mask-aware 晚融合建立透明 baseline，再比较具备跨模态交互和样本自适应可信度权重的候选模型；分类与回归共同训练但分别评价。
4. **解释与复核层**：将模态层面的贡献、模态内时间位置的重要性和反事实遮挡验证结合，最终生成可定位到文本片段、音频区间或视频帧的解释卡。

全流程必须维持题面规定的数据边界：附件 2 的 train/valid/test 结构不可混用；附件 3、附件 4 无标签数据只作最终推理；不得引入外部情感数据用于训练、微调、阈值选择或结果统计。`aligned_50.pkl` 与 `unaligned_50.pkl` 二选一，且 `text` 与 `text_bert` 二选一；选择及理由应固化在配置中。

## 分问题建模安排

### 问题 1：特征提取与时序对齐

输入是 100 条原始视频、转写文本和连续/三分类标签。首先以 `video_id` 与 `clip_id` 组成稳定主键，检查标签表、视频文件和派生特征是否一一对应；随后分别抽取或记录文本 token 时间轴、音频帧时间轴、视频帧时间轴。透明方案是以文本词元或固定时间窗为锚点，对音频和视觉表示做池化/插值，生成带 `valid_length` 与 padding mask 的统一序列。若采用非对齐版本，则保留三个独立时钟并在融合层以 cross-attention 建立对应关系，不得在预处理阶段伪造一一同步。

问题 1 的验收不以预测性能为主，而以可复核性为主：100 条样本均有处理状态；每条样本包含 ID、原始有效时长、三模态特征维度、序列长度、对齐规则和异常标记；至少选择一条典型样本，展示文本片段、音频区间、视频帧段与最终序列位置的映射。预训练特征提取工具可以用于基础处理，但版本、模型、参数、设备和失败重试规则必须写入日志。

### 问题 2：局部模态缺失下的鲁棒预测

预测目标包含三分类极性与连续情感强度。建议先建立两个可解释 baseline：单模态模型（文本、音频、视觉各一）和三模态 masked late fusion。后者对每一模态编码后进行有效长度池化，以显式缺失 mask 控制加权融合；分类头采用交叉熵，回归头采用 MAE 或 Huber 损失，联合目标可写为

`L = lambda_cls * L_cls + lambda_reg * L_reg + lambda_consistency * L_consistency`，

其中各权重只能通过验证集选择。训练期在题给训练样本上模拟连续片段缺失，缺失类型、起点、长度和随机种子必须记录；模拟机制的目的仅是提高鲁棒性，不能窥视附件 3 的无标签样本分布。

进阶候选是“可信度门控的跨模态时序融合”：每个模态编码器输出表示与质量/可用性分数，门控网络基于缺失 mask、有效长度和局部不确定性自适应分配权重，跨模态注意力只在可用位置交互。为避免把注意力权重误当因果解释，模型优劣应通过相同切分下的 Accuracy、macro/micro F1、MAE、Pearson 和按缺失类型/位置/长度分层的退化曲线判断。复杂模型必须超过 late fusion baseline，且报告参数量、训练时间和方差，否则不应作为主模型。

### 问题 3：可解释性情感预测

问题 3 可复用问题 2 的编码器，但应在完整模态输入上单独输出：极性、强度、模态贡献、主要参考模态、关键时间位置及其原始素材定位。建议将三类解释合并：模态级门控/消融差异表示“哪种模态重要”；模态内积分梯度、遮挡或时间注意力表示“哪个局部位置重要”；反事实删除高重要片段与低重要片段的预测变化表示“解释是否具有忠实性”。

验证集应先做解释一致性检查：移除高重要片段的置信度或回归输出变化应显著大于随机/低重要片段；同一输入的小扰动不应造成主要模态频繁跳变；时间位置必须能够在问题 1 的映射表中找到对应的文本、音频或视频区间。附件 4 仅输出全量预测与解释文件，不能计算或宣称其 Accuracy、F1、MAE、Pearson 等真实性能。

## 实施模块、基线与验收

| 模块 | 最小可用实现 | 进阶实现 | 核验重点 |
| --- | --- | --- | --- |
| 数据审计 | 文件清单、PKL 结构摘要、标签/长度/缺失统计 | 可交互数据字典和异常样本报告 | ID、数量、形状、切分边界、读取异常 |
| 对齐 | 固定窗口或词元锚点池化 | 非对齐 cross-attention 与可学习时间偏移 | 原始时间轴可回溯、padding 无泄漏 |
| 情感预测 | 单模态和 masked late fusion | 可信度门控跨模态时序融合 | 与 baseline 的公平比较和重复实验 |
| 缺失鲁棒 | 训练期随机连续 mask | 质量估计、跨模态补偿/蒸馏 | 缺失类型、位置、长度分层退化 |
| 可解释性 | 模态消融与时间遮挡 | 积分梯度、反事实一致性与解释卡 | 忠实性、稳定性和原始素材定位 |
| 提交材料 | 预测 CSV、配置、运行说明 | 模型权重、可视化与解释汇总 | 题面字段、大小上限、匿名性 |

建议代码接口按“只读数据加载器 -> 可复现预处理器 -> 模型 -> 评估器 -> 导出器”划分。每个模块的输入和输出都应包含 `id`、版本标识、有效长度/缺失 mask（适用时）和随机种子；不允许用数组位置替代跨文件样本主键。实验至少固定三组随机种子，报告均值和离散程度；若资源不足无法完成多次训练，须明确报告限制，不能以单次最优结果替代稳健性结论。
