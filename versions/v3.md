# 版本分析

- ## 1. 版本定位与任务边界

  v3 在 v2 的总体方案和数据审计设计基础上，正式聚焦 E 题问题一的解题与建模。问题一的目标不是直接训练情感分类器，也不是直接复用公开论文的预测指标，而是针对附件 1 的 100 条英文原始视频，建立文本、语音、视觉三模态情感特征提取、组织和时序对齐模型，并输出能够被问题二和问题三复用的标准化特征及其可追溯证据。

  本版本遵守以下边界：原始视频、文本和标签只读；不替换、增补或删除样本；异常片段只能采用有记录的掩码、截断或保留策略；外部论文和 GitHub 项目只用于方法启发与基线设计，不能把其结果写成当前项目结果；附件 2 的训练/验证/测试边界、附件 3 和附件 4 的无标签专项测试边界不能被破坏。

- ## 2. 现有资料形成的研究认识

  CMU-MOSEI 资料显示，研究路线大致经历了“高阶融合与动态记忆—跨模态 Transformer 与预训练语言模型—对比/解耦表示—可靠性、不确定性和可解释融合”的演进。TFN 说明三模态存在高阶交互，MFN 和 Dynamic Fusion Graph 强调模态内动态与跨模态异步关系，MAG 说明非文本信息可以通过门控注入文本表示；较新的 COLD、RAF-Net、E-MoE、HCRL、超图和 KAN-MCP 等工作则将重点转向缺失、噪声、模态可靠性和解释忠实性。

  这些资料对问题一的直接结论是：时序对齐不能简化为把三个张量调整成相同长度。必须明确每个特征位置的时间语义、有效长度、填充规则和原始素材映射；如果没有真实逐词时间戳，推断得到的时间位置必须标明来源和不确定性。TFN、MFN、MulT 等预测模型可用于检验特征组织是否有用，但不能代替问题一的特征提取、时间轴记录和全量覆盖证明。

  资料还形成了一个重要的解释性约束：注意力、门控权重或动态融合图只能作为解释候选，不能单独证明模型依据。问题三需要通过模态消融、局部时间遮挡、置换或反事实实验检验解释是否真正改变预测；因此问题一输出的时间映射必须足够细，才能支持后续回溯。

- ## 3. 问题一的数学对象

  对第 `i` 条原始视频样本建立稳定主键
  `sample_id = video_id + "_" + clip_id`，并定义三类带时间索引的输入：
  \[
  X_i^{(T)}=\{x_{i,r}^{(T)},\tau_{i,r}^{(T)}\},\quad
  X_i^{(A)}=\{x_{i,r}^{(A)},\tau_{i,r}^{(A)}\},\quad
  X_i^{(V)}=\{x_{i,r}^{(V)},\tau_{i,r}^{(V)}\}.
  \]
  其中 `T`、`A`、`V` 分别表示文本、语音和视觉，`\tau` 表示特征位置对应的时间区间；文本若无观测时间戳，则必须记录其时间信息来源。

  各模态特征提取器写为
  \[
  z_{i,r}^{(m)}=f_m(x_{i,r}^{(m)};\theta_m),\qquad m\in\{T,A,V\}.
  \]
  若采用公共时间窗 `I_{i,k}`，则第 `k` 个对齐位置的模态特征定义为
  \[
  h_{i,k}^{(m)}=\operatorname{Agg}\left(\{z_{i,r}^{(m)}:\tau_{i,r}^{(m)}\cap I_{i,k}\neq\varnothing\}\right),
  \]
  有效标记为
  \[
  q_{i,k}^{(m)}=\mathbf{1}\left(\exists r,\tau_{i,r}^{(m)}\cap I_{i,k}\neq\varnothing\right).
  \]
  `q` 用于区分真实特征、自然缺失和统一长度产生的 padding，不能仅用全零值推断三者含义。最终输出应包含 `H_i^{(m)}`、`valid_length`、`padding_mask`、时间映射和异常标记。

- ## 4. 建议的可执行流程

  1. **样本与标签核验**：读取附件 1 的视频目录和 `label-100.xlsx`，用 `video_id`、`clip_id` 建立主键；检查 100 条样本是否覆盖、主键是否唯一、视频文件与文本/标签是否一一对应，不能使用目录顺序代替主键。
  2. **原始媒体审计**：记录视频可读性、时长、帧率、分辨率、音频流存在性和实际有效时长；检查文本编码、空文本、异常字符和长度；异常样本不静默删除，形成处理状态表。
  3. **三模态特征提取**：分别生成文本语义、语音声学/韵律、视觉表情/动作特征。工具、预训练模型、版本、参数、设备、输出维度、失败重试和随机种子必须写入运行配置。预训练模型只能作为基础特征提取工具，不能引入外部情感数据训练或调参。
  4. **固定时间组织方案**：建议优先选择具有明确时间语义的固定时间窗或文本词元锚点，将语音和视觉特征按区间进行均值、最大值或时间加权池化；如果采用非对齐方案，则保留三套独立时间轴，并将跨模态对应关系留给后续融合层，不能在预处理阶段伪造同步。
  5. **长度与掩码处理**：统一记录序列长度、有效长度、padding 比例、截断区间和模态有效掩码。padding 不得参与池化、标准化或损失计算；局部零区间不能直接当作 padding，须根据原始有效区间和缺失规则区分。
  6. **证据导出**：输出特征文件、样本索引表、时间映射表、异常处理表、配置文件和运行日志，使任意一个序列位置能够回溯至文本片段、音频时间段或视频帧段。

- ## 5. 方案选择与资料方法的关系

  问题一可形成两类候选方案，但本版本必须选择并固定一种作为主方案：

  - **统一时间窗/词元锚点对齐**：实现透明、易审计、便于问题三回溯；缺点是需要处理不同采样率和文本时间戳不足的问题。
  - **非对齐多时间轴**：保留各模态原始序列，后续用 cross-attention 或软对齐学习关系；信息损失较少，但更难证明每个跨模态关系的时间含义。

  CTC 式软对齐、MulT 跨模态 Transformer、MFN 动态记忆和 TFN 高阶交互均适合作为后续预测或对比方案；它们不能替代问题一的主键、时间戳和审计表。若使用预计算的 `aligned_50.pkl` 或 `unaligned_50.pkl`，必须说明其与附件 1 自主提取特征的关系，不能把附件 2 的标准化特征直接表述为本版本完成了原始视频特征提取。

- ## 6. `Multimodal-Sentiment-Analysis` 工程的复用判断

  该项目可以作为问题二/三的下游基线参考，但不能直接作为问题一解法。其有价值部分是：提供 MulT 跨模态 Transformer、TFN 风格三模态外积、aligned/unaligned 两种输入接口、CTC 式软重采样以及 MAE、相关系数、Accuracy、F1 等评估思路。

  直接复用存在明显限制：项目读取的是特定结构的 `mosei_senti_data.pkl`，不负责附件 1 原始视频和 100 条样本审计；数据类没有将有效长度和局部缺失 mask 传入模型；模型主要输出一个连续回归值，再通过阈值获得二分类，不能直接满足 E 题极性分类与强度回归的双任务接口；padding 未被完整屏蔽；CTC 位置是固定长度的伪位置，不能自动证明对应真实词元或音视频时间戳；工程没有标准化输出解释卡、关键时间段和反事实忠实性检验。

  因此，推荐保留其模型思想，重写数据和训练接口：
  `E-q pkl -> text/audio/vision + valid_length + modality_mask -> mask-aware encoder -> 极性分类头 + 强度回归头 -> 分层评估与解释导出`。复用顺序应为单模态和 masked late fusion、再接 MulT、最后才考虑 TFN 高阶交互；已有 `mult_MULT.pt` 不能作为 E 题结果使用。

- ## 7. v3 的输出与验收标准

  本版本至少应产出：

  - 100 条样本的全量汇总表：主键、原始有效时长、模态处理状态、特征维度、序列长度、对齐粒度、padding 比例和异常标记；
  - 特征文件格式、字段字典、读取示例、版本号和固定配置；
  - 至少 1 个典型样本的文本片段、音频区间、视频帧段、序列位置和三模态特征对应展示；
  - 文件清单、标签覆盖、主键唯一性、特征形状、有效长度范围、padding/mask 逻辑和跨文件错配检查结果；
  - 特征提取工具版本、依赖环境、随机种子、运行日志、失败清单和可复现命令。

  验收重点是“完整、可核验、可复现、可回溯”，而不是问题二或问题三的最佳预测指标。问题一只有在全量样本状态、时间映射和异常处理均有记录后，才能作为后续建模的有效输入。

- ## 8. 已确认事项与待确认风险

  已确认：问题一使用附件 1 的 100 条英文原始视频；研究对象为文本、语音、视觉三模态；需要明确特征定义、提取方法、对齐规则、文件组织和复现流程；CMU-MOSEI 资料支持动态跨模态建模、显式可靠性和解释忠实性等后续方向。

  待通过运行确认：具体特征提取工具和维度、原始视频音频流质量、文本时间戳是否可用、对齐锚点与池化规则、异常样本数量、特征文件与原始素材的 ID 对应关系，以及统一长度 padding 是否会造成信息污染。

  主要风险包括 `video_id/clip_id` 错配、音视频时长不一致、文本时间戳缺失、采样率差异、padding 参与计算、异常样本被静默删除和 aligned/unaligned 混用。每项风险都应由自动化检查、抽样可视化和独立复现控制；在没有运行日志和全量核验表之前，不能宣称对齐质量或特征效果已经验证。
