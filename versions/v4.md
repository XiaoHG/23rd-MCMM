# 版本分析

## 1. 版本定位与范围

v4 在 v3 已完成的问题一透明特征提取与时序组织基线上，转向 E 题问题三“可解释性多模态情感预测”的分析和建模。问题三的目标不是只输出一个情感标签，而是在附件 2 训练/验证边界内建立可复现的预测模型，并对每条样本同时给出情感极性、连续情感强度、三模态作用程度、主要参考模态以及可回溯到文本片段、音频时间段和视频帧的局部证据。

本版本只分析问题三及其所需的前置接口，不改变原始题面、附件数据、问题一历史输出或问题二/三尚未验证的结果。`CMU-MOSEI/q_3/` 中的论文仅用于方法学习、相关工作和候选方案设计；论文中的实验指标、外部数据集结果和公开代码结果不能直接写成 E 题当前项目结果。

## 3. 文献资料对问题三的共同启示

当前 q_3 资料覆盖的研究方向可以归纳为四类：

1. **原生可解释融合**：通过动态路由、门控、专家选择、图/超图或显式模态权重，使模型内部产生模态作用分数。其优点是解释与预测同一结构产生，缺点是内部权重不一定等价于真实决策贡献，必须做忠实性验证。
2. **反事实和事后归因**：遮挡某一模态或局部时间段，比较干预前后的预测变化；也可使用积分梯度、SHAP 或置换方法获得归因。其优点是接口清晰、可复用问题二主干模型，缺点是计算量较大，并且遮挡基线可能引入分布外输入。
3. **可靠性和不确定性建模**：为文本、音频和视觉估计质量、证据强度或预测不确定性，再以样本级门控完成融合。它可以支持“主要参考模态”的判定，但可靠性分数不能直接等同于正确率或因果贡献，必须在验证集上通过消融、校准和选择性预测检验。
4. **预测与证据定位联合学习**：增加局部证据定位分支，将预测损失与定位损失联合优化。E 题没有逐词、逐帧情感原因标注，因此直接监督定位不可行，必须采用弱监督或后验归因，并明确定位结果是模型证据而非人工标注的真实情感原因。

这些资料支持一个稳妥的论证原则：问题三应同时提供“预测结果”和“证据影响”，但不能把注意力权重、门控权重或专家激活值单独当作解释结论。解释是否可信，需要用模态遮挡、局部时间遮挡、置换或反事实预测变化进行验证。

## 4. 面向 E 题的问题三方案框架

建议将问题三建模为多任务预测与可解释归因的组合：

### 4.1 输入与预测任务

对附件 2 的每个样本输入三模态特征、有效长度和 `modality_mask`。训练、验证和测试必须严格使用同一版本的 `aligned_50.pkl` 或 `unaligned_50.pkl`，不能将二者混用；`text` 和 `text_bert` 只能选一个，不能把它们视为第四模态。

预测头至少包含：

- 情感极性分类头，报告 Accuracy 和 F1，并在验证集确定标签映射和必要阈值；
- 情感强度回归头，输出题面要求范围内的连续值，报告 MAE 和 Pearson 相关系数。

训练只使用附件 2 的训练集拟合参数；验证集用于模型、超参数、阈值和解释规则选择；附件 3 和附件 4 无标签，只能在模型固定后进行最终推理，不能用于训练、调参、早停或真实性能统计。

### 4.2 推荐的分层实现顺序

1. **透明基线**：带掩码的单模态池化和三模态 late fusion，先确认标签映射、有效长度和指标实现正确。
2. **时序融合基线**：接入 MulT/跨模态 Transformer，所有注意力和池化显式传入 `modality_mask`，避免 padding 或无效窗口污染。
3. **鲁棒增强**：在训练集模拟连续时间区间缺失，加入模态 dropout 或质量门控；缺失规则、比例和窗口位置必须记录并与附件 3/4 的最终推理分开。
4. **解释模块**：用完整输入与模态遮挡的预测差异计算模态贡献，用滑动时间窗遮挡或积分梯度定位局部证据，并通过 `time_mapping.csv` 映射为文本、音频和视觉原始位置。
5. **必要时再做联合定位**：只有在弱监督定位规则、验证集忠实性指标和消融结果支持的情况下，才加入证据定位分支；不能因为文献结构复杂就直接写成已验证创新。

对当前项目而言，最可复现的主路线是“问题二主干预测模型 + 反事实遮挡解释 + 时间映射回溯”。它可以复用问题二的预测接口，降低重新训练多套复杂模型的风险；动态门控、专家、不确定性或联合定位可作为对照和创新增强，而不是未经验证的默认结论。

## 5. 问题三的解释输出契约

每条样本的解释结果至少应能通过稳定的 `sample_id` 与输入特征关联，并包含：

| 输出字段 | 含义 |
| --- | --- |
| `sample_id` | 样本稳定主键 |
| `pred_sentiment_label` | 预测情感极性 |
| `pred_regression` | 预测情感强度 |
| `modality_contrib_text` | 文本模态贡献分数及归一化规则 |
| `modality_contrib_audio` | 音频模态贡献分数及归一化规则 |
| `modality_contrib_vision` | 视觉模态贡献分数及归一化规则 |
| `main_modality` | 由预先固定规则确定的主要参考模态 |
| `key_timestep_text` | 关键文本位置，并映射到词元或时间窗 |
| `key_timestep_audio` | 关键音频窗口及起止秒数 |
| `key_timestep_vision` | 关键视觉窗口及帧区间 |
| `explanation_method` | 遮挡、反事实、积分梯度或其他实际使用的方法 |
| `fidelity_check` | 验证解释片段影响是否大于低重要性片段的记录 |

贡献分数的计算公式、遮挡基线、归一化方式、关键片段数量和并列处理规则必须写入运行配置。解释结果应能沿 `sample_id -> feature_row_index -> time_mapping/text_token_mapping` 回溯到输入位置；仅输出不可回溯的注意力矩阵不满足题目要求。

## 6. v4 的创新点候选与证据要求

结合 q_3 资料和现有工程，当前可以形成以下候选创新点，但均需实验确认：

- **掩码感知的模态贡献解释**：将有效长度和局部模态缺失纳入反事实遮挡，区分“没有观测”与“真实低响应”，避免零值误判。
- **预测、可靠性和解释的一致接口**：同时输出情感预测、模态可靠性和反事实贡献，并检验可靠性排序是否与遮挡造成的预测变化一致。
- **跨模态时间证据回溯**：将统一窗口索引映射到文本、音频秒区间和视觉帧区间，形成可复核的证据卡，而不是只报告抽象权重。
- **解释忠实性评估**：比较遮挡高重要片段和低重要片段后的预测变化，报告删除曲线、排序一致性或相对影响；这部分结果必须来自附件 2 的有标签验证数据，附件 4 只能生成解释文件。

上述内容是实验假设和方案候选，不是当前已经证明的创新成果。论文中只有在固定数据切分、随机种子和基线后得到可重复的消融证据，才能将其表述为本项目创新。
