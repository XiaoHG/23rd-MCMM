## 二、问题三的建模方案

当前方案以 `aligned_50.pkl` 的三模态时序特征为输入，使用统一的有效长度和掩码处理不同样本的序列。其技术路线为：

```text
对齐的文本、语音、视觉特征
    → 仅用训练集拟合标准化参数
    → 掩码感知的模态投影
    → 模态内 Transformer 编码
    → 以文本为查询的音频/视觉跨模态注意力
    → 动态门控融合
    → 三分类头与情感强度回归头
    → 局部窗口和模态遮挡敏感性分析
    → 证据映射、关键帧和解释卡生成
```

设样本的三模态序列为 $X^{(m)}\in\mathbb{R}^{T\times d_m}$，其中 $m\in\{t,a,v\}$ 分别表示文本、语音和视觉模态，$T$ 为统一后的序列长度，$d_m$ 为模态特征维数。当前实际维数为文本 768、语音 74、视觉 35。通过训练集统计量进行标准化后，模型先完成各模态投影和时序编码，再利用文本查询其他模态，得到跨模态表示。动态门控用于学习样本级模态融合权重，最终同时输出三分类概率和情感强度回归值。论文中应说明分类任务和回归任务是联合输出，不能将门控权重直接解释为因果贡献。

## 三、数据边界、输入与输出

本次运行使用 `aligned_50.pkl`，其 SHA-256 为 `66e867aa74bc70a844e806e5571e371c9abb4a35f9e2887ce9b4d97ff2cb8fcd`。训练集、验证集和测试集的样本数分别为 3395、728 和 727；随机种子为 20260924。模型参数、训练标准化参数、运行配置和训练日志均保存在 `model_artifacts/` 中，可由 `best_model.pt` 和相应配置复现实验流程。

附件二的 train、valid、test 划分严格保持边界：训练集用于拟合模型和标准化参数，验证集用于模型选择和早停，测试集仅用于最终的有标签性能报告。附件四包含 20 个无标签样本，仅用于最终推理和解释展示，不参与训练、调参、早停、阈值选择或真实性能统计。标签映射已核验为 $0$ 对应 Negative、$1$ 对应 Neutral、$2$ 对应 Positive。论文中必须明确附件四只能报告预测结果及解释证据，不能报告 Accuracy、F1、MAE 或 Pearson。

输出主要包括三类内容：第一类是 `predictions_*.csv`，记录样本编号、真实标签（有标签划分）、预测类别、类别概率和情感强度；第二类是 `local_importance_*.csv` 与 `evidence_mapping_*.csv`，记录模态或局部窗口遮挡后的敏感性变化及其到文本窗口、音频时间段和视觉关键帧的映射；第三类是 `keyframes/`、`evidence_cards/` 及其 JSON 元数据，用于把数值解释回溯到可检查的视觉证据。所有结果还应结合运行配置、输入清单、校验和与审计文件使用，避免脱离运行上下文单独引用表格。

## 五、可解释性与论文支撑材料

当前解释机制采用训练集均值 `train_mean` 作为基线，在标准化训练特征空间内进行局部反事实遮挡；窗口长度为 7，步长为 7，保留每个样本贡献排名靠前的 3 个窗口。解释值表示模型输出对模态或局部窗口变化的敏感性，`impact_score` 不是因果效应，也不是人工标注的真实情感原因。文本证据采用对齐后的相对窗口定位，不能表述为逐词精确时间戳；音频和视觉证据则应通过时间区间、关键帧文件名和 JSON 元数据进行回溯。

可用于问题三论文的图表和证据包括：技术路线图、模型结构图、数据边界图、训练曲线、三种数据划分的局部重要性热力图、门控权重与贡献关系图、映射质量图、验证集和测试集混淆矩阵、回归诊断图、分类报告、模态移除诊断、代表性样本选择表及证据示例表。`keyframes/` 和 `evidence_cards/` 应作为定性案例支撑，论文中每张图和每个表都要说明数据划分、统计对象、字段含义及其与模型输出的对应关系。

## 六、与问题三要求的符合性

当前方案已覆盖问题三要求的主要组成：有明确的三模态输入和时序掩码，有分类与回归两个输出，有训练/验证/测试边界，有可复现的随机种子、特征版本、模型权重和运行配置，有模态及局部窗口层面的解释结果，并能将解释结果映射到文本、音频和视觉证据。输出目录也遵循每次运行建立时间戳子目录的约定，能够追溯到对应运行。

## 七、尚未完成项与写作限制

当前仍存在以下需要在论文中如实说明的限制：

1. 尚未完成不同模型结构的重新训练基线对比，因此不能把固定模型的模态移除结果写成完整消融实验或单模态重训练对照。
2. 当前主要结果来自单一随机种子，尚无多随机种子均值、标准差或置信区间，不能据此声称统计显著性和充分稳定性。
3. 视频审计中仍有部分附件四视频出现容器声明帧数与实际解码帧数不一致的记录，相关样本应在论文材料中标记为数据质量审计事项。
4. 文本证据是对齐相对窗口，不是逐词级时间戳；图表说明必须采用与实际输出一致的表述。
5. `impact_score` 和模态门控值只反映当前模型的敏感性或融合状态，不代表真实情感成因。

因此，v9 论文材料应只使用已经存在且可审计的结果，将未完成实验列为局限性或后续工作，不补写虚构的基线、重复实验、置信区间和人工真实性标签。最终写作材料按版本要求整理到 `draft/q_3/v2/`，正文需由团队结合图表编号、公式编号和篇幅要求进行人工复核后使用。
